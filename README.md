Milestone 1: Frontend Implementation Overview

This milestone focused on the development and implementation of the frontend user interface for my project. The frontend components have been successfully created and are ready for integration with the backend services in future milestones.

Milestone 2: 

In this milestone, I built the database system for my project using MySQL with more than 5 connected tables. I created all the DAO classes needed to work with the database (I was successful in populating my database when running the test.php), allowing my website to add, read, update, and delete data. With this backend foundation complete, I can now move forward to create the service layer that will connect my frontend to this database system.

Milestone 3:

With this milestone, I have completed the backend of my project. I implemented the business logic, added the presentation layer, and generated a visual API documentation page using Swagger (http://localhost/Web%20Programming/backend/public/v1/docs/). This has been the most challenging milestone so far due to the number of components that needed to be added. It also served as a great way to visually represent the application's processing logic. This has definetly improved my understanding of the backend structure.
